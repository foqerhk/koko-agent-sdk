# 本地隐私步骤与可见目标

账户恢复凭证、私密认证数据和密码的展示、备份、验证或导入，必须由用户在宿主内完成。SDK 在这些页面暂停任务，不代选敏感验证项、不代填密码，也不把页面树、OCR、页面摘要或截图发送给模型。离开隐私页后才恢复；点击“已完成”不能绕过仍在展示的隐私页。

宿主应为敏感内容容器加固定标记，例如 `testID="privacy-sensitive-recovery"` 或 `testID="privacy-sensitive-secret"`。不要把实际恢复数据、私密认证材料或密码拼进 `testID`、无障碍标签或日志。密码输入框应启用 `secureTextEntry`。这些标记应覆盖导入、展示与验证的所有状态。

对于原生树不能可靠识别的页面，宿主应在页面聚焦时调用 `setAppUserGate`，使用不含秘密的通用提示，例如“请在本机完成敏感恢复步骤”，离开后调用 `clearAppUserGate()`。在页面内容出现前设置，在内容移除后清除，避免后台仍挂载的路由干扰当前页。页面标题启发式识别只是兜底，不能替代宿主显式标记。

发送层重新检查当前原生页面，丢弃调用方传入的原始 OCR、摘要和截图字段，从同一份脱敏树生成上传内容。进入隐私步骤时清空规划历史；网关也拒绝已识别的隐私页。调试时仅使用虚构数据验证请求拦截，不用真实秘密测试脱敏。

点击只针对当前可见目标。目标缺失时，SDK 只在原生确认可纵向滚动的容器内执行可见滑动，每次重新读取页面，找到目标后才单次点击。列表不再变化或达到搜索上限时停止并报告未找到，避免连续猜点。

# Security policy

Please do not publish credentials, account-recovery data, private authentication material, exploitable details, or production logs in a public issue. Report suspected vulnerabilities privately to **hello@intentcomputing.cn**, including affected version, impact, and reproduction using synthetic data. Do not include a live secret.

The supported npm release line is 1.x. The SDK cannot replace host-side protection of sensitive screens; follow the [privacy guide](docs/PRIVACY.md) and verify the host and configured gateway before release.
